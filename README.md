## 🚀 Current Projects

### 🧪 ModelScope — Interactive Machine Learning Explorer
*Python · Streamlit · Machine Learning*

An interactive ML learning tool designed to help users experiment with datasets and understand model behavior without treating machine learning as a black box.

- Upload a dataset and select input features and the target variable.
- Configure training and testing splits.
- Train and compare machine learning models.
- Explore model behavior through visualizations and step-by-step explanations.
- Inspect the code behind the models to connect concepts with implementation.

**Goal:** Make machine learning more transparent, interactive, and approachable for learners.

### 🌐 AI Portfolio Builder
*Next.js · React · TypeScript · Prisma · PostgreSQL*

A web application designed to help students create and publish professional portfolios without needing to build a website from scratch.

- Create portfolios using structured profile information.
- Customize portfolio layouts and visual styles.
- Publish portfolios through shareable public URLs.
- Generate QR codes to make portfolios easier to share at networking events.

**Goal:** Lower the barrier for students to showcase their projects, experience, and skills.
